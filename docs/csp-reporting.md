# Content Security Policy (CSP) Reporting Endpoint

## Overview

MediFlow exposes a public HTTP Cloud Function endpoint (`/csp-report`) for collecting and logging
Content Security Policy (CSP) violation reports generated by client web browsers.

Since this endpoint is publicly accessible without user authentication, it includes strict input validation,
body size limits, rate limiting, and defensive exception handling to prevent resource exhaustion and abuse.

## Endpoint Details

- **Path**: `/csp-report`
- **Cloud Function Name**: `cspReport`
- **Access Level**: Public (Anonymous)
- **Supported HTTP Method**: `POST`

---

## Allowed Request Specifications

### 1. HTTP Method

Only `POST` requests are allowed. Any other HTTP method (`GET`, `PUT`, `DELETE`, `PATCH`, `OPTIONS`) will be
rejected with HTTP `405 Method Not Allowed`.

### 2. Content-Type Header

The `Content-Type` header must be one of the following MIME types (optional parameter suffixes such as
`; charset=utf-8` are permitted):

- `application/csp-report` (Standard legacy CSP report directive)
- `application/reports+json` (W3C Reporting API specification)
- `application/json` (Standard JSON payload)

Requests with missing or unrecognized `Content-Type` headers will be rejected with HTTP `415 Unsupported Media Type`.

### 3. Payload Size Limit

- **Maximum Payload Size**: **10 KB (10,240 bytes)**.
- If the `Content-Length` header or the evaluated request body size exceeds 10 KB (or if `Content-Length` is
  invalid or malformed), the request is rejected with HTTP `413 Payload Too Large`.

### 4. Rate Limiting

- **Rate Limit Threshold**: **1 report per IP address per 5 seconds**.
- Requests exceeding this rate limit receive an HTTP `429 Too Many Requests` response.
- Client IP addresses are extracted from the trailing entry in the `X-Forwarded-For` header
  (appended by Google Front End / Cloud Run) to prevent header spoofing.

## Expected Request Formats

The endpoint accepts three standardized CSP report formats:

### Format A: Legacy W3C CSP Report (`report-uri`)

```json
{
  "csp-report": {
    "document-uri": "https://mediflow.app/dashboard",
    "referrer": "https://google.com",
    "blocked-uri": "https://evil.com/malicious.js",
    "violated-directive": "script-src 'self'",
    "original-policy": "default-src 'self'; script-src 'self'"
  }
}
```

### Format B: W3C Reporting API Array (`report-to`)

```json
[
  {
    "type": "csp-violation",
    "age": 10,
    "url": "https://mediflow.app/dashboard",
    "user_agent": "Mozilla/5.0 ...",
    "body": {
      "blockedURL": "https://evil.com/malicious.js",
      "effectiveDirective": "script-src-elem",
      "originalPolicy": "default-src 'self'"
    }
  }
]
```

### Format C: Direct Violation JSON Object

```json
{
  "document-uri": "https://mediflow.app/dashboard",
  "blocked-uri": "https://evil.com/malicious.js",
  "violated-directive": "script-src 'self'"
}
```

## HTTP Response Codes

| Status Code | Reason | Description |
| --- | --- | --- |
| **204 No Content** | Success | Report payload was validated, logged, and processed successfully. |
| **400 Bad Request** | Invalid Payload | Request body is missing, not valid JSON, or missing required CSP report keys. |
| **405 Method Not Allowed** | Invalid Method | Request method is not `POST`. |
| **413 Payload Too Large** | Size Exceeded | Request size or `Content-Length` header exceeds 10 KB limit. |
| **415 Unsupported Media Type** | Invalid Content-Type | `Content-Type` header is missing or unsupported. |
| **429 Too Many Requests** | Rate Limited | Client IP has sent more than 1 report within the 5-second interval window. |
